# 古诗记忆助手

本地古诗文图文理解与背诵工具。家长或老师在备课端确认教材原文和图卡，孩子在学习端完成理解、无提示背诵、整段闯关与间隔复习。

GitHub 搜索关键词：`古诗记忆助手`、`gushi-memory-assistant`、`SKILL.md`。

仓库根目录的 [SKILL.md](SKILL.md) 就是给 AI 助手用的 Skill。下载或复制该文件，放到支持 Skill 的助手里即可：在对话中帮忙拆课文、写理解提示和图卡脚本。完整网页工作台仍按下面步骤在自己电脑运行。课文、图卡和学习记录只保存在使用者自己的浏览器里，不会上传到 GitHub。

## 在电脑上使用

1. 安装 [Node.js](https://nodejs.org/)（LTS 版本即可）。
2. 获取代码，任选一种：
   - 在 GitHub 页面点击 `Code` → `Download ZIP`，解压到任意文件夹；
   - 或使用 Git：

     ```bash
     git clone https://github.com/Dafupo-w/gushi-memory-assistant.git
     ```

3. 打开终端，进入项目文件夹，启动本地服务：

   ```bash
   cd gushi-memory-assistant
   node local-server.js
   ```

4. 用浏览器打开： [http://localhost:8010/workspace.html](http://localhost:8010/workspace.html)

不要直接双击 HTML 文件。PDF、Word、图片的文字提取，以及离线使用，都需要通过上面的本地服务访问。

电脑左侧可切换「备课端 / 孩子学习」；手机打开同一地址时，底部 Tab 也可进入孩子学习页。

## 家长 / 老师流程

1. 在「新建课程」粘贴课文，或导入 PDF、Word、图片、TXT、Markdown。
2. 对照教材校对标题、作者、朝代、背诵范围、原文和标点。
3. 检查自动拆出的记忆意群，按需要修改原文、理解提示和图像脚本。
4. 图卡由使用者自己准备：可检索开放授权素材、配置自己的图片生成服务，或直接上传本地图片。仓库不包含作者个人上传的参考图。
5. 原文已校对且至少有两个意群时即可发布；图卡可以稍后补。
6. 发布后从「课程库」点击「孩子开始学习」。

课程、图卡、学习尝试和复习任务保存在当前浏览器的 IndexedDB。复习阶段采用便于验证的 `0、1、2、4、7、14、30` 天间隔：记住了升一档，有点卡保持当前档但至少安排次日复习，忘记了退回短间隔并安排次日复习。这不是经过教育研究校准的科学模型。备课端可以备份数据，也可以在「学习报告」中查看掌握情况、薄弱句和复习计划。

## 孩子学习流程

1. 看图理解：逐张查看图卡、理解提示和可选原文。
2. 无提示回忆：只看图写出原句；使用提示会被记录。
3. 整段闯关：不显示原文，按课文顺序选择图卡。
4. 结果与复习：根据回忆、提示和排序生成分数与薄弱句；再逐句选择「记住了 / 有点卡 / 忘记了」。

缺少图卡的句子会显示「本句图卡待完成」，孩子仍可先按文字理解和背诵。

## 可选：自动生成图卡

不配置密钥也能使用：粘贴课文、拆分意群、上传自己的图卡、让孩子学习。

如果需要自动检索开放素材或调用图片生成，请在本机复制 `.env.example` 为 `.env`，填入你**自己**申请的 BytePlus ModelArk API Key 和模型 ID，然后重新运行 `node local-server.js`。密钥只留在你的电脑上。

不要把 `.env` 上传到 GitHub、提交进代码，或发到聊天里。本仓库只包含空白的 `.env.example`。

开放素材来自 Openverse。选用前请检查画面是否适合该句，并保留来源信息。下载后的图片保存在当前浏览器课程库中。

## 手机访问与备份

网页支持添加到主屏幕。课程数据仍在当前浏览器本地；清理网站数据会删除它们，请定期在备课端导出备份。

手机与电脑默认不自动同步。若要在同一 Wi-Fi 下用手机打开，把本地 `.env` 中的 `HOST` 改为 `0.0.0.0`，重启服务后使用电脑的局域网 IP 加端口 `8010`。局域网设备默认不能调用付费图片生成；只有确认网络可信且确实需要时，才设置 `ALLOW_LAN_IMAGE_API=1`。

## 系统说明

- 粘贴原文、编辑课程、孩子学习和复习：Windows、macOS 都可以。
- 拖入 PDF / Word / 图片自动抽字：目前依赖 macOS 系统工具。其他系统请直接粘贴课文，图卡仍可自己上传。
